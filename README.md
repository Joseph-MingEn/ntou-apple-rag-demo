# Apple 產品 RAG 搜尋問答示範

以 Apple 台灣官網資料為主題，以 500 筆檢索文件逐步展示關鍵字向量、餘弦相似度、min-heap Top-k、提示詞及附來源的回答。文件包含 200 筆官方產品資訊，以及 300 筆由其中 100 項官方資訊建立的問法索引；索引都參與比對，但同一事實不會重複佔用 Top-k。此靜態教學示範使用人工設計的關鍵字向量和抽取式回答，沒有連接大型語言模型；資料為 2026-11-13 查閱的靜態快照。

直接開啟 `index.html` 或以任意靜態伺服器執行。執行測試：`node --test tests/*.test.js`。GitHub Pages 可使用 main 分支根目錄發布。工作流程見 [文件](docs/工作流程.md)。

可輸入使用需求取得規則式產品建議；推薦不評估價格、預算或相容性，應至官方確認。
