# Apple 產品 RAG 搜尋問答示範

以 Apple 台灣官網資料為主題，以 1,000 筆檢索文件逐步展示關鍵字向量、餘弦相似度、min-heap Top-k、提示詞及附來源的回答。文件包含 477 筆原始資料（包含 200 筆產品資料、229 筆 NCC 型號認證資料及 48 筆歷代產品規格），以及 523 筆由原始資料建立的問法索引；索引都參與比對，但同一事實不會重複佔用 Top-k。此靜態教學示範使用人工設計的 100 維關鍵字向量和抽取式回答，沒有連接大型語言模型；產品資料為 2026-11-13 查閱的靜態快照，NCC 與歷代產品資料為 2026-11-15 查閱的靜態快照。檢索加入型號篩選與字元雙字重疊分數，並以規則拒答價格及部分不在範圍的問題；此規則無法辨識所有問法。回答以資料和固定句型整理，並非模型生成。

直接開啟 `index.html` 或以任意靜態伺服器執行。執行測試：`node --test tests/*.test.js`。GitHub Pages 可使用 main 分支根目錄發布。工作流程見 [文件](docs/工作流程.md)。

可輸入使用需求取得規則式產品建議；推薦不評估價格、預算或相容性，應至官方確認。
