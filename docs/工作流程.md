# 工作流程紀錄

## 1. 範圍
以 Apple 台灣產品為題，製作可在 GitHub Pages 執行的 RAG 搜尋問答教學示範。參考提供的畫面，以問題向量、逐筆比對、最小堆積 Top-k、提示詞及回答呈現流程。

## 2. 規格
- 提供範例與自訂問題；顯示主題向量、餘弦相似度、閾值、堆積、步驟、來源與答案。
- 上一步、下一步、自動播放與重設可操作；手機與桌面均可閱讀。
- 資料為 Apple 台灣官網公開資訊的人工整理快照，附官方連結與查閱日期；不承諾即時更新。
- 教學用關鍵字向量與抽取式回答，不聲稱呼叫大型語言模型；無相關資料時明確說明。
- 全部在瀏覽器執行，不需要金鑰或伺服器。

## 3. 計畫
先撰寫核心邏輯測試並確認失敗，再實作資料、向量與 min-heap 流程；接著製作介面與操作，執行測試及瀏覽器驗證，最後發布。

## 4. 計畫審查
靜態託管無法安全存放 API 金鑰，也不提供模型推論；因此採可解釋的模擬流程，明示限制。產品資訊可能變更，避免價格等易變資料並附來源。相似度 0 與閾值以下必須排除，避免捏造答案。查詢可包含多產品，保留 Top-k 並用引文連結追溯。

## 5. TDD
先以 Node 內建測試建立餘弦、向量、最小堆積、門檻、無結果及完整搜尋測試，確認缺少實作時失敗，再完成程式並重跑。
