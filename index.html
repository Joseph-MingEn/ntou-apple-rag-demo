HOW RAG WORKS

RAG 如何找到答案？

RAG 是「檢索增強生成」（Retrieval-Augmented Generation）。系統先從知識庫找資料，再讓語言模型參考資料回答問題。

01 / RETRIEVE

檢索 Retrieval

將問題與文件轉成可比較的向量，計算相似度，找出與問題最相關的資料片段。

02 / AUGMENT

增強 Augmentation

將檢索到的片段與原始問題放進提示詞，提供回答時需要的參考脈絡。

03 / GENERATE

生成 Generation

一般 RAG 系統會把提示詞交給語言模型，依據參考資料生成回答，並可附上來源供查證。

以「iPad 使用什麼晶片？」為例

找到 iPad 晶片相關文件 → 將文件與問題組成提示詞 → 根據文件回答並提供來源連結。

認識限制：檢索結果與來源品質會影響回答；即使有來源，語言模型也可能出錯，仍應查證原文。本頁是教學示範：以關鍵字計數和餘弦相似度模擬檢索，直接摘錄文件作答，沒有呼叫大型語言模型。
